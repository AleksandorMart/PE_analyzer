
# 🛡️ PE Analyzer — Инструмент классификации PE-файлов на основе машинного обучения

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Status](https://img.shields.io/badge/status-production--ready-green.svg)]()

**PE Analyzer** — это десктопное приложение для автоматического анализа PE-файлов (Windows executables) с использованием ансамбля моделей машинного обучения. Инструмент позволяет специалистам по информационной безопасности быстро классифицировать файлы как безопасные или потенциально вредоносные.

## ✨ Возможности

### 🎯 Классификация файлов
- **Анализ одиночных файлов** — быстрая проверка конкретного PE-файла
- **Пакетная обработка** — рекурсивный анализ всей директории с фильтрацией PE-файлов
- **Настраиваемая чувствительность** — параметр "Степень подозрительности" (0.0-1.0) для управления порогом классификации
- **Мгновенные результаты** — вывод вероятностей для каждой модели в реальном времени

### 📊 Отчётность
- **Текстовые отчёты** — структурированные таблицы с результатами по степеням подозрительности
- **Excel-экспорт** — числовые данные с автофильтром, сортировкой и форматированием
- **Дедупликация** — автоматическое устранение дубликатов при повторных проверках

### 📈 Аналитика
- **Визуализация метрик** — просмотр ROC-кривых и матриц ошибок обученных моделей
- **Сравнение моделей** — графическое сравнение производительности всех алгоритмов
- **Zoom-область** — детализированный анализ критической области ROC (низкий FPR, высокий TPR)

### 🖥️ Графический интерфейс
- **Двухвкладочный интерфейс** — разделение классификации и аналитики
- **Неблокирующая работа** — многопоточная обработка без зависания UI
- **Удобная навигация** — кнопки выбора файлов/папок, ручное введение путей
- **Очистка сессии** — возможность начать новую проверку без перезапуска приложения

## 🏗️ Архитектура

### Модели машинного обучения
Система использует ансамбль из **6 моделей** для повышения точности и надёжности классификации:

| Модель | Тип | Особенности |
|--------|-----|-------------|
| **GradientBoosting** | Ансамбль (бустинг) | Высокая точность, устойчивость к переобучению |
| **LogisticRegression** | Линейная | Быстрая, интерпретируемая, базовый бейзлайн |
| **ExtraTrees** | Ансамбль (деревья) | Экстремальная рандомизация, низкая дисперсия |
| **RandomForest** | Ансамбль (деревья) | Устойчивость к шуму, хорошая обобщающая способность |
| **SVC** | Метод опорных векторов | Эффективность в высокоразмерных пространствах |


### Извлекаемые признаки (30+)
Система извлекает комплекс признаков из PE-структур:

- **Метаданные файла**: размер, временная метка, архитектура
- **Энтропия**: общая и по секциям (индикатор упаковки/шифрования)
- **Импорты**: количество, подозрительные API (инъекции, обход защиты)
- **Экспорты**: количество экспортируемых функций
- **Заголовки**: точка входа, размеры, выравнивание, контрольная сумма
- **Секции**: размеры, характеристики, сигнатуры упаковщиков
- **Директории**: наличие Debug, Resource, TLS (индикаторы обфускации)

## 📖 Использование

### Шаг 1: Формирование датасета

Поместите образцы файлов в соответствующие директории:
- `data/benign/` — легитимные PE-файлы (например, из `C:\Windows\System32`)
- `data/malware/` — вредоносные образцы (из коллекций типа VirusShare, MalwareBazaar)

Запустите сбор признаков:
```bash
python build_dataset.py
```

Результат: файл `pe_dataset.csv` с извлечёнными признаками и метками.

### Шаг 2: Обучение моделей

Запустите скрипт обучения:
```bash
python train_models.py
```

Процесс включает:
- Загрузку и предобработку данных
- Разделение на train/test (80/20)
- Масштабирование признаков (StandardScaler)
- Обучение 6 моделей
- Генерацию метрик (Accuracy, ROC-AUC, Confusion Matrix)
- Сохранение моделей и визуализаций

Результаты:
- `saved_models/*.pkl` и `*.keras` — обученные модели
- `saved_models/scaler.pkl` — объект стандартизации
- `plots/*.png` — графики и матрицы ошибок

### Шаг 3: Запуск GUI-приложения

```bash
python gui_app.py
```

#### Интерфейс классификации:
1. **Выбор пути**: нажмите "Выбрать файл" или "Выбрать папку", либо введите путь вручную
2. **Настройка чувствительности**: введите значение от 0.0 до 1.0 (рекомендуется 0.5-0.8)
3. **Запуск анализа**: нажмите "Классифицировать"
4. **Просмотр результатов**: в текстовом поле отобразятся вероятности для каждой модели
5. **Экспорт**: используйте "Создать отчёт" (TXT) или "Выгрузка в Excel" (XLSX)

#### Интерфейс аналитики:
- Переключитесь на вкладку "2. Аналитика"
- Просматривайте ROC-кривые и матрицы ошибок
- Используйте колесо мыши для прокрутки графиков

#### Очистка сессии:
- Нажмите "Очистка логов" для начала новой проверки
- Подтвердите действие (предварительно сохраните отчёт, если нужно)

## 🗂️ Формирование датасета

### Источники данных

#### Легитимные файлы (Benign)
- Системные файлы Windows (`C:\Windows\System32\*.exe`, `*.dll`)
- Программное обеспечение из официальных источников
- Open-source проекты с проверенной репутацией

#### Вредоносные файлы (Malware)
- **VirusShare** (https://virusshare.com/)
- **MalwareBazaar** (https://bazaar.abuse.ch/)
- **theZoo** (https://github.com/ytisf/theZoo)
- **Kaggle Malware datasets**

### Рекомендации по датасету
- **Баланс классов**: стремитесь к соотношению 1:1 (benign:malware)
- **Объём**: минимум 1000 файлов каждого класса для надёжного обучения
- **Разнообразие**: включайте разные типы PE (EXE, DLL, SYS, SCR)
- **Актуальность**: используйте свежие образцы (последние 2-3 года)

## 🎓 Обучение моделей

### Процесс обучения
1. **Загрузка данных**: чтение `pe_dataset.csv`
2. **Предобработка**:
   - Приведение к числовым типам
   - Замена `NaN` и `inf` на медианные значения
3. **Разделение**: `train_test_split` (80% train, 20% test, стратификация)
4. **Масштабирование**: `StandardScaler` (Z-score нормализация)
5. **Обучение**: циклическое обучение всех 6 моделей
6. **Оценка**: вычисление метрик на тестовой выборке
7. **Сохранение**: сериализация моделей и артефактов

### Метрики качества
- **Accuracy**: доля правильных предсказаний
- **ROC-AUC**: площадь под ROC-кривой (оптимально > 0.95)
- **Confusion Matrix**: матрица ошибок (TP, TN, FP, FN)

### Визуализации
- **ROC-кривые**: сравнение всех моделей на одном графике
- **Zoom ROC**: детализация критической области (FPR 0-0.15, TPR 0.85-1.0)
- **Confusion Matrices**: тепловые карты для каждой модели

## 🔧 Технические детали

### Извлечение признаков
Модуль `feature_extractor.py` использует библиотеку `pefile` для парсинга PE-структур:

```python
from feature_extractor import extract_features

features = extract_features("sample.exe")
# Возвращает словарь с 30+ признаками
```

### Порог классификации
Параметр "Степень подозрительности" (`degree_suspicion`) управляет порогом:
```
threshold = 1.0 - degree_suspicion
prediction = "Malware" if probability >= threshold else "Benign"
```

**Примеры**:
- `degree_suspicion = 0.5` → `threshold = 0.5` (сбалансированный режим)
- `degree_suspicion = 0.8` → `threshold = 0.2` (высокая чувствительность, больше False Positives)
- `degree_suspicion = 0.2` → `threshold = 0.8` (низкая чувствительность, больше False Negatives)

### Многопоточность
GUI использует `threading.Thread` для неблокирующей работы:
- Загрузка моделей выполняется в фоне при старте
- Классификация файлов запускается в отдельном потоке
- Логи передаются через `queue.Queue` для потокобезопасности

### Формат отчётов

#### TXT-отчёт
```
=== ОТЧЕТ ПРОВЕРКИ ===
Дата: 2026-07-09_14-30-45
==============================

--- Степень подозрительности: 0.5 (Порог Malware: 0.50) ---
Файл                                    GradientBoosting    LogisticRegression  
malware1.exe                            Malware (0.9876)    Malware (0.9543)    
benign1.exe                             Benign (0.0123)     Benign (0.0234)     
```

#### Excel-отчёт
- Один лист "Results" со всеми файлами
- Столбцы: `Файл` | `GradientBoosting` | `LogisticRegression` | ... | `SVC`
- Числовые значения (float) для сортировки
- Автофильтр и закреплённая шапка
- Автовыравнивание ширины столбцов
- Обводка контуров таблицы

- **100 файлов**: ~30-60 сек
- **1000 файлов**: ~5-10 мин

## 🐛 Известные ограничения

1. **Только PE-формат**: анализ работает только с Windows executables (EXE, DLL, SYS, SCR)
2. **Статический анализ**: не выполняется динамический анализ поведения файла
3. **Зависимость от датасета**: качество классификации зависит от репрезентативности обучающих данных
4. **Упакованные файлы**: сильно упакованные/зашифрованные образцы могут давать ложные срабатывания
5. **Ложные срабатывания**: легитимные файлы с нестандартной структурой могут быть классифицированы как вредоносные
